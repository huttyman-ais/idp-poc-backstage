## Changing infrastructure

Open a PR against this repo. `.github/workflows/terraform.yaml` runs `terraform plan` and posts
the plan as a PR comment; merging to `main` runs `terraform apply`.

## Outputs

Run `terraform output` locally, or check the latest `terraform.yaml` Actions run summary for:
`acr_login_server`, `postgres_fqdn`, `key_vault_uri`, `frontend_url`, `backend_url`.
